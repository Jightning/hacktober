# UI fonts

Roboto (400, 500, 600, 700) and a small Material Symbols Outlined subset are served locally.

Sources:
- https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;600;700&display=swap
- https://developers.google.com/fonts/docs/material_symbols

The symbol subset contains arrow_downward, arrow_upward, auto_awesome, check, check_circle, close, delete, edit, folder_open, menu, menu_open, and science. These are original Google icons, not custom drawings. See the adjacent licenses.
